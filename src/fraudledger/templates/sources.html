Public working set

This is the path that scores real billing. It loads the OIG exclusion list, hospice enrollments and owners, home-health enrollments and owners, and NPPES when the CMS index is online. It loads the latest Medicare hospice and home-health provider files, plus Hospice Care Compare and Home Health Care Compare. It then loads Medicaid and keeps hospice, home health, and personal-care procedure codes, removes fictional demonstration rows, and scores what loaded. The Medicaid file itself is still multi-gigabyte. Monthly patient counts in that file are kept. A payment jump that only tracks the patient count, or that barely changes paid per patient, is not flagged. Care Compare is corroboration. It is not loaded as a Critical finding by itself. HCRIS cost reports, SAM.gov, and state Medicaid exclusion lists are not part of this pull.
